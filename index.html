Current implementation boundary

Sandbox transactions are read-only.

In the current Developer Platform implementation, the sandbox transactions endpoint validates an environment-bound API key and returns persisted transaction records. Transaction processing is not implemented there, so the collection may be empty; the endpoint does not initiate or simulate a payment.
