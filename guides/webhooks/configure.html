Webhook guides

Configure delivery Live

The webhook endpoint, signing secret, and channel preferences are scoped with the pilot team. These docs do not describe a self-service setup endpoint.

Prepare the receiver

  • Coordinate the endpoint and delivery preferences with the pilot team.
  • Store the signing secret in protected storage and keep it out of source control and logs.
  • Implement signature verification and idempotent handling before accepting production traffic.

See webhook delivery for the receiver requirements and contact support to coordinate configuration.
