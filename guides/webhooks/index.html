Webhook guides

Webhook guides Live

These guides cover PesaGuard outbound webhook delivery to systems you operate: configure the receiver with the pilot team, verify deliveries, and process retries safely.

Outbound webhooks are not provider callbacks

PesaGuard webhooks are sent to your receiver. Payment-provider callbacks travel in the opposite direction and can have a different signature format.

Follow the receiver flow

  1. Coordinate delivery configuration with the pilot team.
  2. Verify the signature before trusting or persisting an event.
  3. Use the event catalog and current deployment contract; event payload fields may still change.
  4. Make event handling idempotent so retries do not repeat business effects.

For the full delivery behavior, see the webhook delivery reference and retry guidance.
