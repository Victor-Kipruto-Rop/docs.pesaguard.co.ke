Events Draft

Use the event catalog for current event names and the deployment's OpenAPI document for the current payload contract.

Event-specific payload fields are still being stabilized. The individual event references are useful for consumer behavior, but should not be treated as a guarantee that every field is final.

Current references

  • Event catalog — published event names.
  • transaction.created, transaction.matched, and transaction.unmatched.
  • reconciliation.completed and anomaly.detected.

Before binding application logic to a payload, check the live OpenAPI contract served by your deployment.
