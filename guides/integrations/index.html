Integration guides M-Pesa only

M-Pesa (Daraja) callback validation and reconciliation is the only provider integration documented as current. Other rails remain planned and do not have a verified PesaGuard adapter contract here.

  • M-Pesa (Daraja) — the current callback and matching scope.
  • Airtel Money, bank rails, and point of sale — planned; no adapter is documented.
  • Custom provider — a connector abstraction is evaluated, not implemented.

This describes callback ingestion and reconciliation, not the Developer Platform's sandbox transaction listing. That listing is read-only and does not process or simulate payments. Use the API reference and the live deployment's OpenAPI contract for request details.
