Integration guides

Custom provider Planned

A provider-connector abstraction is being evaluated, not implemented. There is no published generic endpoint or custom-provider contract.

Do not assume an adapter interface

The current M-Pesa integration does not imply that arbitrary provider payloads can be submitted through the same flow. Multi-rail support requires a separate scope and a verified contract.

Current documented scope

See M-Pesa (Daraja) for the provider flow documented as current, or contact support to discuss requirements for another provider.
