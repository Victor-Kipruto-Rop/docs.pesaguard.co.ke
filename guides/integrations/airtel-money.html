Integration guides

Airtel Money Planned

Airtel Money integration is planned. No PesaGuard adapter, tests, or verified request and callback contract is documented today.

Not an available integration

Do not assume an Airtel Money callback can be sent to the M-Pesa flow or to the Developer Platform sandbox transaction listing. The sandbox listing is read-only and does not process or simulate payments.

Current documented scope

For the provider integration documented as current, see M-Pesa (Daraja). For Airtel Money provider payloads, use the provider's official documentation until a PesaGuard adapter contract is published.
