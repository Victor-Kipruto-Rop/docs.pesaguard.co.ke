Anomaly guides

Severity Live

Anomaly severity is a routing priority that helps distinguish review urgency. The current schema permits low, medium, and high.

  • Severity does not declare fraud or authorize an automatic block.
  • Use the signal's evidence and transaction context alongside severity.
  • Record the human review outcome and reason separately.

The schema defines the available values but does not assign a universal response policy to each one. See the anomaly schema and the investigation guide.
