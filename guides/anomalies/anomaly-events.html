Anomaly guides

Anomaly events Draft

The anomaly.detected event signals that a named rule or statistical check flagged a transaction for human review.

The event-specific payload fields are still being stabilized. Use the live deployment's OpenAPI contract before depending on field-level details; the anomaly schema describes a signal, not the full webhook envelope.

Handle the signal safely

  • Verify the PesaGuard webhook signature before persisting or acting on the event.
  • Use the signal as a review prompt, not as a confirmed-fraud label or automatic blocking instruction.
  • Record any reviewer decision separately in the audit trail.

See the event reference for current consumer guidance, the verification steps, and the OpenAPI reference for the deployment contract.
