Anomaly guides

Risk signals Live

The current anomaly schema names the patterns below. A signal is context for review, not a standalone conclusion about fraud.

  • amount_deviation — an amount differs from the expected pattern.
  • velocity_spike — activity changes sharply within an evidence window.
  • duplicate_reference — a reference has been seen before.
  • unusual_timing, repeated_failures, and unexpected_channel — additional named patterns in the current schema.

These are the schema's signal names, not a promise that every signal is enabled for every deployment. See the anomaly schema and the anomaly concept for field meaning and review context.
