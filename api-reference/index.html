API reference

OpenAPI contract

The authoritative document is served by the deployment you call at /openapi.json. This checked-in mirror supports offline review and client generation; compare it with the target deployment before relying on it.

Files

  • Download openapi.json — the mirror, OpenAPI 3.0.3, Dashboard document version 2.0.0.
  • Download openapi.yaml — the same document in YAML.
  • examples/transactions.json, examples/reconciliation.json, examples/anomalies.json, examples/webhooks.json.
  • schemas/ — JSON Schema for the canonical shapes.

Explore operations

Search the mirrored OpenAPI contract by path, method, tag or summary. Expanding an operation shows documented parameters, request and response schemas, and a copyable cURL template. The explorer does not send requests or accept credentials.

Request execution is intentionally unavailable

This documentation does not provide a public sandbox or a verified non-production API target. Do not paste live credentials into a documentation page. Use your provisioned environment and a local client when you are authorized to make requests.

Generate a client

curl -sS "$PESAGUARD_API_URL/openapi.json" -o openapi.json
npx @openapitools/openapi-generator-cli generate -i openapi.json -g python -o ./client
The target deployment wins

If this mirror and the deployment you are authorized to use disagree, that deployment is authoritative. Re-generate clients from its document before a release.
