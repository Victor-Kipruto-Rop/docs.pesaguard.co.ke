API reference

OpenAPI contract

The authoritative document is served by your own deployment at /openapi.json. The copy in this folder is a mirror kept for offline reading and client generation.

Files

  • openapi.json — the mirror, OpenAPI 3.0.3, dashboard version 2.0.0.
  • openapi.yaml — the same document in YAML.
  • examples/transactions.json, examples/reconciliation.json, examples/anomalies.json, examples/webhooks.json.
  • schemas/ — JSON Schema for the canonical shapes.

Generate a client

curl -sS "$PESAGUARD_API_URL/openapi.json" -o openapi.json
npx @openapitools/openapi-generator-cli generate -i openapi.json -g python -o ./client
The live deployment wins

If this mirror and your deployment's document disagree, the deployment is authoritative. Re-generate clients from the live document before a release.
