Docs/Changelog/October 2026

Documentation · 7 October 2026

October 2026

These changes improve documentation navigation and clarify evidence boundaries. They do not announce an API, payment-processing, or production-readiness release.

DOCUMENTATION · DOMAINS

Canonical ecosystem links

Production-facing documentation links now use the PesaGuard .co.ke domains for product, Developer Platform, API and status references. The links identify intended origins; this update does not verify their DNS, TLS, deployment or reachability.

DOCUMENTATION · API REFERENCE

Searchable OpenAPI operation browser

The reference page now filters operations from the checked-in OpenAPI mirror and shows the operation's documented parameters, schemas, responses and a cURL template. It does not execute calls or accept credentials because no public self-serve sandbox is documented.

DOCUMENTATION · AI INDEX

Added LLM documentation indexes

llms.txt and llms-full.txt provide concise and expanded indexes with the same API-version, sandbox and production-evidence caveats as the human-readable docs.

DOCUMENTATION · TRUST

Environment guidance now requires verification

Staging and production are described as intended environments rather than confirmed live deployments. Verify protected-environment deployment, migrations, Redis, backups and restore, email, provider callbacks and metrics with the target operator.

Consumer action

Fetch /openapi.json from the deployment you are authorized to use before generating a client. Do not treat the API document version, documentation link, or configured environment as evidence of a live capability.
